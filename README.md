## 现在关注什么？

以问题驱动的方式逐步探索 AI4S，不预设单一专业、模型或研究终点。可能涉及：

- AI 辅助科学模拟、逆向设计、材料与分子发现；
- 物理约束模型、神经算子、科学基础模型、生成式模型；
- 主动学习、自动化实验、科研 Agent 与设计—验证闭环；
- AI4S 的可靠性、成本、泛化、可解释性、实验验证；
- 未来 5—10 年的科学研究方式与产业机会（明确区分事实、推断和设想）。

这只是讨论范围，**并非新的强制任务清单**。
