# AI × 超材料：一周文献调研执行工作流（v1.0）

> 日期：2026-10-14｜周期：2026-10-14—10-20  
> 定位：**探索性 / 范围性文献调研**，不声称达到穷尽检索的系统综述标准。  
> 原则：**人工主导问题定义、证据核查与科研判断；Agent 承担检索、去重、信息提取、整理和反向审查。**

## 0. 任务目标与边界

**一周总目标**：对“AI 与超材料”的研究方向建立可解释、可追溯的初步知识框架；掌握若干代表性方法的思路、证据与局限，并能提出后续值得核查的科研问题。

### 暂定研究范围（Day 1 后可修正）
- **核心对象**：电磁超材料与超表面，兼顾微波、太赫兹、光学频段。超表面是相关平台，不代表全部超材料。
- **主轴 A：AI → 超材料**。正向预测/代理模型、逆向设计/优化、物理约束与数据效率、可重构结构的智能控制。
- **主轴 B：超材料 → AI/计算**。波基神经网络、模拟计算、可编程超表面计算。注意：**并非所有波计算均属于 AI**。
- **外围扫描**：声学、力学、热学超材料中的 AI 设计，只用于识别可迁移方法；第一周不平均分配精读时间。
- 暂不安排：穷尽所有论文、复杂全波仿真复现、对“完全无人做过”作确定性判断。

### 调研问题
1. RQ1：AI 与超材料有哪些主要互动关系、研究任务和物理平台？
2. RQ2：正向代理、逆向设计、物理约束、智能控制和波计算分别解决什么问题？
3. RQ3：相对合理的非 AI 基线，AI 究竟改善了精度、设计质量、总成本还是实时性？
4. RQ4：论文使用了什么验证手段，证据受哪些结构、频段、数据分布与实验条件限制？
5. RQ5：有哪些由现有证据支持的技术瓶颈、争议与后续研究机会？

### 最终交付物
- 一张领域地图（按**研究对象—研究任务—技术方法—验证方式**组织）。
- 候选文献库（建议 20—40 篇，附 DOI/可靠链接、筛选记录；**数量不是 KPI**）。
- 核心论文阅读卡（建议 6—10 篇，重点看证据，不求读得多）。
- 技术路线比较矩阵（任务、输入输出、训练数据、基线、验证、成本、局限）。
- 一份可讲解的调研结论与汇报提纲，能区分事实、作者声称、个人推断和未核实内容。

## 1. 人工与 Agent 分工

| 环节 | 你负责 | Agent 负责 | 检查点 |
|---|---|---|---|
| 范围 | 定义研究边界和优先级 | 提出关键词与候选分类 | Gate 0 |
| 检索 | 检查覆盖、追踪重要论文 | 扩展检索式、检索元数据、去重 | Gate 1 |
| 筛选 | 审核核心及边界论文 | A/B/C 初筛、标注理由 | Gate 1 |
| 阅读 | 理解物理、算法、原始证据 | 提取结构化信息、解释概念 | Gate 2 |
| 综合 | 判断是否可比、推理是否成立 | 构建比较矩阵、寻找反例 | Gate 3 |
| 汇报 | 独立表述、审查最终结论 | 组织初稿、核对引用一致性 | Gate 3 |

Agent 1/2/3 可理解为三种**工作角色**，不需要在本周先编写多智能体编排程序。优先一个 Agent 分阶段执行，留人工闸门。

## 3. 检索协议

### 检索入口
- Google Scholar：建立种子论文、查看前向与后向引用关系。
- Web of Science / Scopus（如有权限）：结构化检索与候选记录导出。
- 出版商/期刊原站、DOI：核验论文元数据、正文、补充信息。
- arXiv：跟踪未正式发表的新方法，**预印本与同行评审版本分开标注**。
- Zotero：保存最终核验文献，不把 Agent 的自由文本当成书目权威。

### 初始检索式（适配数据库语法）
```text
("metamaterial*" OR "metasurface*")
AND ("machine learning" OR "deep learning" OR "artificial intelligence")
AND ("inverse design" OR "forward prediction" OR "surrogate model" OR "optimization")
```
```text
("metasurface*" OR "programmable metamaterial*")
AND ("intelligent control" OR "reinforcement learning" OR "adaptive sensing")
```
```text
("metasurface*" OR "metamaterial*")
AND ("optical neural network" OR "diffractive neural network" OR "analog computing")
```
```text
("physics-informed" OR "physics-guided" OR "data-efficient" OR "active learning")
AND ("metasurface*" OR "electromagnetic metamaterial*")
```
```text
("acoustic metamaterial*" OR "mechanical metamaterial*")
AND ("machine learning" OR "inverse design")
```

**执行方式**：宽词检索 → 阅读综述分类 → 从综述参考文献反向追踪 → 从代表论文向前追踪 → 用遗漏类别补查（meta-optics、frequency-selective surface、nanophotonics 等）。

**纳入**：与 RQ1—RQ5 有关、有可信原始出处、研究任务明确；综述用于地图，原创研究用于验证方法。  
**排除或降级**：重复记录、与研究问题明显无关、没有可核实出处、与已收录工作完全重复且没有增量。  
**边界案例**：设 `adjacent` 标签，不因为没有出现“metamaterial”字样就草率排除相关波器件方法。

每次检索都记录：日期、数据库/搜索平台、完整检索式、筛选规则、结果数（仅在实际可获得时填写）、纳入/排除理由。不得捏造数据库精确命中数。

### 阅读优先级
- **A / 精读**：与核心问题直接相关，具有代表性，且能核对重要证据。
- **B / 结构化浏览**：补充背景、竞争方法、技术链条或不同场景。
- **C / 保留索引**：目前相关性较低或高度重复；随研究方向调整可升级。
- 优先保证**任务、物理平台和技术路线的多样性**，不按期刊影响因子机械排序。

## 4. 三层阅读协议

| 层次 | 参考耗时 | 操作 | 判断标准 |
|---|---|---|---|
| 第一轮：快速浏览 | 5—10 分钟 | 标题、摘要、关键图、结论 | 能说出问题—方法—结果，判断 A/B/C |
| 第二轮：结构化阅读 | 20—40 分钟 | 引言、框架、实验/仿真、对照、局限 | 能解释为什么这样做、用什么证据证明 |
| 第三轮：精读 | 约 1 小时至数小时 | 物理方程、参数化、损失函数、数据、验证、代码/补充材料 | 能审查关键条件并回答技术追问 |

不重要的数学细节可以标注待学；关键公式、假设或实验条件直接影响结论时必须深入。

### 单篇论文阅读卡模板
```markdown
## P-ID｜论文题名
- 作者/年份/期刊/DOI：
- 类型：综述 / 研究论文 / 预印本
- 证据来源：仅摘要 / 已看正文 / 已看补充材料
- 研究对象：材料、结构、频段、边界条件
- 研究任务：正向预测 / 逆向设计 / 优化 / 智能控制 / 物理计算 / 其他
- 问题和研究动机：
- 输入 → 输出：
- 算法、物理约束与非 AI 基线：
- 数据生成、训练和测试：
- 验证：理论 / 全波仿真 / 实验 / 跨结构泛化
- 定量结果（注明指标、单位、基线和条件）：
- 成本：数据生成 + 训练 + 优化/推理 + 验证：
- 作者声称的主要贡献（原文位置）：
- 原文实际支持的结论（页码/图/节）：
- 局限和替代解释：
- 我的判断：
- 待核查问题：
- 证据等级：E0 未核 / E1 仅摘要 / E2 正文核查 / E3 独立或补充证据核查
```

### 跨论文比较矩阵（D6 使用）
| ID | 研究问题 | 平台/频段 | 输入→输出 | AI方法及非AI基线 | 数据与总计算成本 | 实际验证 | 改进点 | 不可比条件与局限 |
|---|---|---|---|---|---|---|---|---|

不要直接比较跨论文报告的“加速倍数”或“误差”：它们可能使用不同结构空间、目标函数、硬件、训练样本和频段。对于训练型方法，至少考虑

`总成本 ≈ 数据生成 + 训练 + 设计/推理 + 仿真/实验验证`

如同一模型可重复复用，应明确摊销到多少个设计任务。

## 5. 文献与 Agent 的质量控制

1. **论文真实**：每篇有 DOI、出版商页或可信索引链接。已发表版本与预印本去重。
2. **证据可追溯**：关键定量结果记录出自论文哪一节、哪张图或哪张表。只看摘要就必须注明“仅摘要”。
3. **三层表达分离**：`作者声称`、`原文证据支持`、`我的推断`。三者不能混写。
4. **不补全不存在的数据**：看不到训练样本量、误差定义、验证条件时写“未核实”，不能让模型猜。
5. **审查比较条件**：优先寻找合理基线，区分单次推理速度与端到端成本。
6. **检索可修正**：新发现的技术路线可以修改最初分类和检索式。
7. **研究空白需克制**：“当前样本中尚未找到”不等于“此前无人研究”。

### 可复制的 Agent 提示词

**A｜检索与去重助手（D2—D3）**

> 你负责“AI 与电磁超材料/超表面”文献初筛。根据 RQ1—RQ5 搜集可核查论文，输出：准确标题、作者、年份、论文类型、期刊/平台、DOI 或出版商链接、检索来源、日期、研究任务分类、建议 A/B/C 级及理由。不要虚构 DOI，不要把检索到的摘要当作已阅读全文；用 DOI 去重，保留 adjacent 案例；额外说明可能遗漏的技术路线和下一轮搜索词。

**B｜结构化证据助手（D4—D5）**

> 仅依据可实际访问的原始全文/PDF（或明确指出仅摘要），使用阅读卡逐项记录物理平台、输入输出、算法、训练数据、对照基线、验证和局限。重要数字附论文节/图/表/页。分列“作者声称”“证据能证明什么”“你的疑问”，没有依据填“未核实”。最后列出三项人工应复核的问题。

**C｜反向质疑与比较助手（D6）**

> 给你若干阅读卡与出处，请先判断研究任务、物理平台、目标函数、数据和硬件是否一致，再比较方法的性能。明确单次预测与端到端优化成本的区别。针对每条综合结论找潜在反证/替代解释，标注支持该结论的论文 ID 和证据位置。不得以“没看到论文”认定“未有人做过”。

**D｜报告审计助手（D7）**

> 核对综述初稿中每条重要结论的来源是否真实、引用是否匹配、是否误把综述转述当原始实验、是否混淆“AI 辅助设计”“AI 智能控制”“超材料物理计算”。指出证据不足、不公平比较和有争议之处，并按“问题—严重度—需要回查的原文—修复建议”输出。

## 6. 人工检查点（Quality Gates）

### Gate 0 — D1 结束
- [ ] 能自己解释“AI for metamaterials”和“metamaterials for AI”的差异。
- [ ] 能按**对象、任务、方法、验证**描述一篇论文，而非只说算法名字。
- [ ] 至少 2 篇综述已快速浏览，其中 1 篇重点读了原文。
- [ ] 记录至少 3 个自己的认识或判断、2 个不懂的问题。
- [ ] 明确本周后续准备重点研究哪 1—2 条技术路线（可暂定）。

### Gate 1 — D3 结束
- [ ] 文献有元数据、DOI/链接、筛选原因和检索日志，去重完成。
- [ ] 通过前向/后向引用追踪校验检索覆盖。
- [ ] 精读清单覆盖不同研究问题和验证方式，而非重复收录相似工作。
- [ ] 核心文献中包含适当的非 AI 比较基线或基线方法参考。

### Gate 2 — D5 结束
- [ ] 核心论文有问题—方法—证据—局限阅读卡。
- [ ] 主要指标、对照方案、仿真和实验条件可以回到原文定位。
- [ ] 至少能解释两条路线的优势及**何时不能直接比较**。
- [ ] 未核实结论已明确标记。

### Gate 3 — D7 结束
- [ ] 领域地图不混淆材料平台、研究任务、算法与应用。
- [ ] 最终报告关键结论有可追溯参考文献。
- [ ] 所谓研究机会包含限制条件、不确定性和可能反证。
- [ ] 能不看稿解释至少三条路线和至少两项有证据的技术局限。

## 8. D1 核验过的起点论文

### 综述
- **R01｜Qian, Kaminer & Chen (2025)**, *A guidance to intelligent metamaterials and metamaterials intelligence*, Nature Communications 16, 1154. https://doi.org/10.1038/s41467-025-56122-3  
  整体双主轴入口。重点看 Abstract、Fig. 1、Fig. 2、两大主章节及 Outlook。出版商页面注明 2025-12-18 有作者更正，应使用更新后版本。
- **R02｜Ma, Feng et al. (2026)**, *Artificial intelligence with metasurfaces: from intelligent design to intelligent computing*, PhotoniX 7, 23. https://doi.org/10.1186/s43074-026-00239-1  
  较新的双主轴综述，重点观察 Sect. 2 智能设计与 Sect. 3 智能计算。
- **R03｜Ji, Chang, Xu et al. (2023)**, *Recent advances in metasurface design and quantum optics applications with machine learning, physics-informed neural networks, and topology optimization methods*, Light: Science & Applications 12, 169. https://doi.org/10.1038/s41377-023-01218-y  
  较深入的超表面设计方法综述，覆盖 ML、物理信息方法及拓扑优化，也包含量子光学应用，不代表全领域。

### 原创论文种子（先看摘要；不等于已经完成精读）
- **P01｜Peurifoy et al. (2018)**, *Nanophotonic particle simulation and inverse design using artificial neural networks*, Science Advances 4, eaar4206. https://doi.org/10.1126/sciadv.aar4206  
  早期 ANN 辅助正向/逆向设计，属于纳米光子学相邻方法范例。
- **P02｜Liu, Tan, Khoram & Yu (2018)**, *Training Deep Neural Networks for the Inverse Design of Nanophotonic Structures*, ACS Photonics 5, 1365–1369. https://doi.org/10.1021/acsphotonics.7b01377  
  逆问题非唯一性与 tandem 网络方法学范例。
- **P03｜Li et al. (2019)**, *Machine-learning reprogrammable metasurface imager*, Nature Communications 10, 1082. https://doi.org/10.1038/s41467-019-09103-2  
  微波可编程超表面 + 机器学习测量优化，属于智能成像而非单纯结构逆向设计。
- **P04｜Lin et al. (2018)**, *All-optical machine learning using diffractive deep neural networks*, Science 361, 1004–1008. https://doi.org/10.1126/science.aat8084  
  波基/衍射神经网络代表性工作；衍射光学系统不都等同于“超表面”，阅读时注意边界。
