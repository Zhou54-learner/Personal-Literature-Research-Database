# 一天内最小实验（提案）：固定人类目标的 Agent × 2-bit 超表面阵列优化

> **状态：仅为计划，尚未开始实施，未获得实验结果。**
>
> 研究者 2026-10-14 明确提出：第一版不研究 Agent 自主修改科研目标，先掌握计算层；如果时间允许，准备一个总投入不超过一天的最小演示，支持与导师沟通文献调研后的兴趣及初期设想。这不是完整的人类介入密度 Benchmark，也不能声称有统计效力。

## 1. 首版研究边界

- **人类在运行前确认并锁定**：研究目标与观测方向、阵列尺寸、物理简化条件、评分标准、搜索空间、计算预算及允许的 Agent 操作权限。任务文件 `spec.json` 版本化；运行中不得被 Agent 修改。
- **计算层**：独立 Python 数值程序负责阵列因子、GA 优化、损失计算、记录结果。LLM 的文本输出不当作电磁预测或高保真验证。
- **Agent 编排层**：只通过固定工具接口读取优化进展、决定授权范围内的继续、重启或调整搜索超参数；超预算、修改科研目标或物理模型时应请求批准或拒绝，不得擅改。
- **人类决策点**：前期锁定目标；只有越权提案、不可自动解决的异常时中途介入；结果最终由研究者审查。第一版不测量最优审核密度。

## 2. 选择最简单的物理计算沙盒：1D 阵列因子

选择 R02 `meta-array design` 的教学型例子，而非第一天就接 CST 或重建本科三维电阻膜吸波工程，以降低仿真接口/许可/材料模型调试风险。若将来需要，可用真实电磁仿真替换计算模块，保持 Agent-优化器边界基本不变。

**建议冻结的示例规格：**
- 16 个理想等幅反射单元，沿 x 等距排列 `d = λ/2`，法向平面波入射。
- 2-bit 离散相位：`{0, π/2, π, 3π/2}`；设计变量为 16 维离散编码 `g_n ∈ {0,1,2,3}`。
- 远场只考虑 `xz` 二维观察截面，有符号角 `θ ∈ [-90°,90°]` 相对于法线；非三维圆锥辐射模式。
- **固定的人类目标**：在 `θ_1=-30°` 与 `θ_2=+30°` 附近形成两个清晰波束，并尽量压低其他方向旁瓣。不允许 Agent 在运行过程中改变该目标。
- 简化阵列因子：`AF(θ;g)=(1/N) Σ_{n=0}^{N-1} exp[i(φ(g_n)-knd sinθ)]`，`I(θ;g)=|AF|²`。为便于公平比较，所有编码使用相同归一化方式。
- **指标选择注意**：如果优化 `I(-30°)+I(30°)`，算法可能只增强其中一束。建议先写一个固定的多目标标量化示例，例如 `score=min(I(-30°), I(30°)) - α·max_{θ∉目标角窗}I(θ)`，两侧目标角窗和系数 α 由人类在开始前确认。目标角窗需足够覆盖主瓣而非把主瓣边缘误作“旁瓣”；先测试解析边界情形。该评分是**数值方向图代理分数**，并非电磁能量效率或实测吸收率。
- **物理有效性验证**：全相同相位应出现法线附近主瓣；`φ_n=nπ/2` 与 `φ_n=-nπ/2` 对应两侧约 30° 的单波束；这些 sanity checks 在 GA 之前必须通过。
- **物理局限**：只计算独立理想等幅单元的远场阵列因子，无元胞方向图、真实反射损耗、偏振、互耦、有限厚度、边缘衍射或全波网格求解。故**只能验证优化与人机编排的可运行性，不能验证实际超表面性能**。

理论参考（不是本试验结果）：Analog Devices, *Phased-Array Antenna Patterns—Part 1*, https://www.analog.com/en/resources/analog-dialogue/articles/phased-array-antenna-patterns-part1.html ；R02: Ma et al. (2026) Sect.2.2, DOI:10.1186/s43074-026-00239-1；2-bit 超表面研究背景例：https://www.nature.com/articles/s41598-024-84601-y。

## 3. 最小实现流程

1. **数值物理评估器** `array_factor.py`：对给定编码返回完整方向图和两个目标波束指标；加入上述解析 sanity checks 和固定输入输出 schema。
2. **优化器** `optimize_ga.py`：种群产生→批量阵列因子评价→评分→交叉/变异→重复，保存收敛记录、候选编码及随机种子。明确 GA 是生成搜索候选的算法，而阵列因子模块才是电磁响应近似计算者。
3. **受限编排层** `orchestrator.py`：读取 `spec.json` 与状态 JSON；只准调用 `run_optimize`、`evaluate`、`plot`、`ask_human` 等显式函数。Agent 可在剩余预算内选择固定范围内的 `restart_seed` / `adjust_mutation` / `stop`；不得直接执行任意 shell，更不得修改冻结物理模型或目标函数。若确需 LLM 控制则接真实可用的模型 API/工具，所有模型决策入日志；没有实际模型决策时称作**规则编排脚本**，不要冒称 Agent。
4. **审批门控测试**：演示一次授权内调度决策，并单独干跑一次越权提案（如请求改变目标波束或超出预算）：应阻止执行并要求人类确认。越权测试不更改科学实验的锁定目标。
5. **最小对照**：普通固定预算的 GA 自动化 vs 同样计算预算下的受限编排版（可用 2–3 个种子做演示，不能据此得出显著性结论）。记录物理指标、评价次数、计算秒数、Agent 额外延迟、人类参与次数及工作分钟数。
6. **产物**：初始与最优的远场曲线；GA 收敛图；`spec.json` 与运行日志；一张“谁负责什么”的双层流程图；一页以内写明前提、结果、限制和后续扩展的导师展示材料。

## 4. 时间盒（总计约 6–8 小时，含适量余量）

| 时间 | 工作 | 可交付检查点 |
|---|---|---|
| 0–1 小时 | 理论核对 + 数值前向计算 + 三项 sanity checks | 可画出 0° 与 ±30° 单波束 |
| 1–3 小时 | 简单 GA + 固定双波束目标/约束 + 日志 | 收敛曲线与可复现种子 |
| 3–4.5 小时 | 明确工具 API + Agent/规则编排层 + 人类门控 | 不可改变锁定规格 |
| 4.5–6 小时 | 基线与编排版对照运行；检查日志/图 | 结果与成本对照表 |
| 6–8 小时 | 整理一页导师简报、复核局限、保存代码和配置 | 具备可展示的最小成果 |

**止损条件**：如 4 小时内尚未完成可靠的前向模型与 GA，则不花时间调试 Agent；优先保留可信的计算层及任务接口。如模型 API 调用不稳定，只做明确标注的规则编排演示，绝不假装 Agent 已实现。若确需 CST/全波验证，另单独排期。

## 5. 成功定义与禁止的过度推论

**PoC 通过**：前向模型 sanity checks 全过；GA 的目标与编码日志可复现；编排层只能经工具接口执行；越权提议在执行前被阻止；图和运行轨迹可解释。

**PoC 不证明**：LLM 改善最终设计质量、Agent 比普通脚本快、最佳人工审核密度、真实超表面能实现该方向图、独立全波/实物效率或方案具备论文创新性。这些都需要后续独立物理 evaluator、更丰富场景和真正的基准研究。
