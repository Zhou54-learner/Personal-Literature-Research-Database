## 1. 原文核查来源及明确可支持的分类

### R01：Qian, Kaminer & Chen (2025), Nature Communications
- 期刊原文：https://www.nature.com/articles/s41467-025-56122-3 DOI https://doi.org/10.1038/s41467-025-56122-3
- **Introduction / Fig.1** 把「AI for metamaterials」总结为 (i) **versatile/accelerated design**（多样化设计加速）、(ii) **automatic/intelligent meta-devices**（自适应智能超器件）、(iii) **physical discovery**（物理规律探索）。
- **同一 Fig.1** 把「metamaterials intelligence / wave-based computing」分为 (i) **wave-based neural network**、(ii) **mathematical operation**、(iii) **logic operation**。**后两类是波物理信息处理，并不自动意味着 AI 神经网络推理**。
- **§ Three design categories: forward prediction, inverse design, and spectral correlation / Fig.2a**：设计加速这一分支下至少三种核心映射任务：(a) `g → s` 已知结构及材料/激励时预测响应；(b) `s_target → g_candidate` 已知期望响应寻找候选结构（非唯一，不保证全局最优）；(c) `s_known → s_other` 借助相关观测响应推断另一种难测/难算响应（例如低频→高频、近场→远场），**不能遗漏 R01 第三类**。
- § Automatic meta-devices / Fig.5 提到 **perception–decision–execution**（感知—决策—执行），开/闭环均有讨论；此为设计之外的动态控制与自适应任务。§ physical discovery 是另一类 AI 帮助揭示隐含物理的方向。
- **R01 的文字“forward mapping single-valued (one-to-one)”不能误推严格 injectivity**：确定结构和物理边值问题通常对应确定场/响应，但不同结构可共享相似或相同的观测响应，因此逆向非唯一。
- 不能把其「三类设计映射」当成全部 AI for metamaterials，亦不能把元胞/阵列尺寸尺度放进这一任务树充作第四种算法。

### R02：Ma et al. (2026), PhotoniX
- 期刊原文：https://link.springer.com/article/10.1186/s43074-026-00239-1 DOI https://doi.org/10.1186/s43074-026-00239-1
- **Chapter 2 / §2.1/§2.2/§2.3** 将 intelligent metasurface design 依次从 **meta-atom（单元结构优化）→meta-array（阵列排列和编码优化）→器件应用**组织；其 §2.1 明确指出 **forward：由给定几何预测目标响应；inverse：由目标生成几何**。因此它支持 R01 的正反向任务区分，但 meta-atom/meta-array 不与之处于同一类目，是**设计对象与空间尺度维度**。
- **Chapter 3 / §3.1–3.4** 将智能计算平台按 **自由空间衍射网络 → 芯片集成光子网络 → 微波可编程超材料网络 → 跨架构对比**展开，是与 R01 计算目标类型（网络、数学、逻辑）不同的**实现平台维度**。
- 特别注意：R02 中自由空间衍射网络可能不是严格由可定义 meta-atoms 构成的二维 metasurface，作为相邻波计算技术时须说明边界，不要把所有衍射器件直接归类为超表面。

## 2. 主讲一张研究问题树：两大主轴、三类研究方向，再下沉一层映射任务

```text
AI × 电磁超材料／超表面交叉领域
│
├─ A. AI 赋能超材料：AI 是方法，电磁结构/器件是研究对象（R01、R02）
│   │
│   ├─ A1. 加速设计（R01）
│   │    ├─ A1a 正向预测：给定结构/材料/工况 → 响应/场/光谱
│   │    ├─ A1b 逆向设计：给定性能目标 → 可行设计参数/结构
│   │    └─ A1c 响应关联：已知某一响应 → 其他频段/表征的响应
│   │
│   ├─ A2. 自适应智能器件（R01）
│   │    └─ 感知环境与需求 → 决策 → 调整可编程器件（开环/闭环）
│   │
│   └─ A3. 辅助物理规律探索（R01）
│        └─ 由数据与物理约束揭示隐含耦合/机制、协助解释
│
└─ B. 超材料赋能计算：电磁波结构是计算媒介（R01、R02）
    │
    ├─ B1. 波神经网络／物理推理
    │    └─ 通过衍射、散射、干涉形成输入到输出的物理映射
    ├─ B2. 数学运算
    │    └─ 利用波调控实现特定线性算子、微分、变换等
    └─ B3. 逻辑运算
         └─ 由电磁器件的输入输出实现逻辑处理
```

**交叉维度（画图时用标签/侧边注释，不变成树的同级研究任务）**：
- R02 **设计尺度**：`meta-atom`（单元几何/材料参数） vs `meta-array`（阵列空间编码/整体功能），可在 A1a/A1b 乃至 A2 任务中出现，并非独立“第四种算法”。
- R02 **计算物理实现平台**：自由空间衍射网络 / 集成光子网络 / 可编程微波网络，可分别实现 B1、也可能与其他运算任务交叉。
- **实现方法层**：CNN/FNN、Tandem、GAN、active learning、GA/PSO、adjoint/topology、PINN（需核实具体物理约束）不是高层任务分类名，最多作为二级标签写在树的最末端；传统伴随/GA不是自动属于 AI。
- **A/B 非互斥**：AI 可能负责设计一块将来用作波神经网络的结构；先分类研究目标/执行计算的媒介，再谈采用哪些算法训练和制造。

## 3. 对用户自己提出的“两类”的判断：正确的方向，但边界需精确

- 用户称「一类目标是形成最优结构」对应 A1b **逆向设计**，更科学地说是形成**满足目标和约束的候选结构**，不能保证 **global optimum**。
- 用户称「一类形成可预测目标函数结果的模型」大体对应 A1a **正向代理模型**。但常见任务是预测完整的响应向量 `s(f)`（反射/透射/吸收、场、方向图），**优化目标函数 `L(g; s_target)` 通常是比较预测响应与目标后另外构造**。某些研究也可直接学习标量目标函数，但不应把正向预测等同于所有“loss模型”。
- A1a + A1b 经常**组合**：高保真求解器产生结构—响应训练集 → 训练正向快速代理 → 由优化算法/逆向 NN 查询代理来寻找满足目标的候选设计 → 最后做独立 Maxwell/实验验证。
- 第三类 A1c **响应之间的映射**是 R01 明列的类别，不能只说“二分类”就漏掉；与逆向不等同，因为结构变量可从预测任务中完全不出现。
