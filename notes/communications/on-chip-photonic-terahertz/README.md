## 已知研究方向与暂未确定的边界

导师细化的方向是：**围绕片上的光学集成技术，在太赫兹波段做通信。**

需要区分：
- **片上光子集成 / PIC（Photonic Integrated Circuit）**：利用芯片上的波导、调制器、探测器等组件操控**光频**信号，是器件/平台技术。
- **太赫兹通信 / THz communication**：以**太赫兹频段电磁波**承载信息的传输系统，是信号频段和通信任务。
- **光子辅助的太赫兹系统**：可能通过光学方法生成、控制、转换或检测 THz 信号，同时使用电子、天线、波导及数字信号处理。**不等于整条 THz 链路必然在芯片内，也不等于全部是光学硬件。**

物理架构参照：[Lampert 等，*Photonics-integrated terahertz transmission lines*, Nature Communications (2025)](https://doi.org/10.1038/s41467-025-62267-y)。该原始工作展示片上光子结构与太赫兹传输线的集成和 THz 产生/检测；**此处仅用于解释可能的技术形态，不作为导师实际选型证据，不代表完整通信系统已实现，也暂不加入主文献索引。**

**暂待导师/技术材料进一步明确（不需要现在逐项询问）：** 目标频段和带宽；THz 在自由空间传播还是在片内/封装内导波；具体光子集成材料和器件；采用光电转换、非线性光学或其他机制；发射端/接收端及天线的划分；当前最突出的是器件转换效率、耦合损耗、相位噪声、传播/色散、调制检测还是系统级控制；有哪些仿真、测量工具和数据。

## 一篇论文如何处理？

**先在广泛调研中读懂它，后来再决定是否转移。** 阅读/讲解按以下逻辑展开：

1. **问题是什么？** 把通信链路的物理过程和技术术语用入门语言讲清楚（首次英文缩写给全称与直观用途）。
2. **传统方案如何工作？** 用最小必要示例说明算法做了什么、为什么可能不足。
3. **AI 具体加在哪一环？** 输入、输出、训练数据、方法与传统方案的区别。
4. **作者提供了什么证据？** 区分作者理论、离线仿真、实际器件实验、外场测试与长期部署，检查比较基线和计算成本。
5. **可否迁移到片上 THz？** 不能只看方法名字，要逐项检查**输入输出对应关系、物理假设、目标器件的约束**；根据证据记录为“待核实 / 条件相关 / 有直接证据”，不能直接宣称适用。

专题中的成熟判断与专项论文检索留在第二阶段。**现有论文仍以 [literature/index.csv](../../../literature/index.csv) 为唯一主元数据源**。通信系统研究归 `communications`，以超材料结构本身为主的研究保持 `metamaterials`；跨领域只使用链接。只有实际获取并具有适当归档权利的 PDF 才能进入 `papers/`，检索日志有实际检索内容才写入 `literature/searches/`。
