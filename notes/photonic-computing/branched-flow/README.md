## 首轮结构化结论

1. **已有原始实验**：2020年肥皂膜观察分叉，2024年液晶电调控，2025年液晶微区定制；2026年PRL发表可编程/各向异性分叉。它们证明“光分叉流可产生、可调、可图案化”的不同层级，但不等于已经训练出执行AI任务的分叉流神经网络。
2. **已有邻近计算证据**：2025年散射介质 Optical NGRC 实现物理特征映射+数字线性读出；2024年非线性无序介质光计算与2018年衍射网络是不同的参照架构。不可将一般多重散射的性能直接归因于分叉流机制。
3. **待验证的关键转化**：输入编码—光学映射—探测非线性—输出读出—训练/重构—任务评价—稳定性/系统开销；重点问分叉流相较均匀介质、普通散射介质和可编程衍射结构有何**独立增量**。
4. **空间/时间必须分开**：原始2020/2024/2025年实验主要是空间分叉；2026年B09是时间域分叉理论/数值工作，不是已有实验的直接复现。
